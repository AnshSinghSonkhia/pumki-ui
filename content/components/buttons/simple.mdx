## Props

| Prop       | Type                                                                                                                                              | Default   | Description                                            |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | --------- | ------------------------------------------------------ |
| variant?   | 'default' | 'destructive' | 'outline' | 'secondary' | 'ghost' | 'link' | 'success' | 'warning' | 'info' | 'dark' | 'light' | 'gradient' | 'glass' | "default" | Style variant for the button.                          |
| size?      | 'default' | 'sm' | 'lg' | 'icon'                                                                                                                  | "default" | Size of the button.                                    |
| asChild?   | boolean                                                                                                                                           | false     | If true, renders children directly with button styles. |
| className? | string                                                                                                                                            | -         | Additional CSS classes for the button.                 |
| children?  | React.ReactNode                                                                                                                                   | -         | Button content.                                        |
| type?      | 'button' | 'submit' | 'reset'                                                                                                                     | "button"  | Button type attribute.                                 |
| ...props   | HTMLButtonElement attributes                                                                                                                      | -         | Any other props for the button element.                |
