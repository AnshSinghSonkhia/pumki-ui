## Props

| Prop             | Type            | Default                            | Description             |
| ---------------- | --------------- | ---------------------------------- | ----------------------- |
| scale?           | number          | 10                                 | Ripple scale factor     |
| transition?      | Transition      | `{ duration: 0.6, ease: "easeOut" }` | Animation config        |
| rippleClassName? | string          | -                                  | Class for ripple effect |
| className?       | className       | -                                  | Class for root element  |
| children         | React.ReactNode | -                                  | Button content          |
