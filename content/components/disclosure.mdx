## Props

| Prop          | Type                | Default   | Description                                                                     |
| ------------- | ------------------- | --------- | ------------------------------------------------------------------------------- |
| children      | React.ReactNode     | required  | Content to display inside the disclosure.                                       |
| className     | string              | undefined | Custom CSS classes for the disclosure container.                                |
| ...aria props | AriaDisclosureProps | —         | All props from react-aria-components (e.g., isOpen, defaultOpen, onOpenChange). |
