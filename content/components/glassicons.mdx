## Props

| Prop      | Type             | Default  | Description                                                                                                                                                   |
| --------- | ---------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| items     | GlassIconsItem[] | required | Array of icon objects to display. Each item includes icon (React element), color (string or gradient key), label (string), and optional customClass (string). |
| className | string           | ""       | Custom CSS classes for the grid container.                                                                                                                    |
