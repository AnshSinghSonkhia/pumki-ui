## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `imageUrl` | `string` | `Moai PNG URL` | Image source for the Moai statues. |
| `count` | `number` | `12` | Number of Moai statues displayed. |
| `speed` | `number` | `1` | Animation speed multiplier. |
| `interactive` | `boolean` | `true` | Enable mouse parallax effect. |
| `zIndex` | `number` | `0` | z-index for the background container. |
| `className` | `string` | `""` | Custom CSS classes for the wrapper. |
| `seed` | `number` | `42` | Seed for deterministic random placement. |
